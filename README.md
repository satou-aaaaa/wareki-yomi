# 和暦よみ

昭和50年は西暦何年？ 平成元年生まれは今年何歳？ 和暦と西暦の読みかえ、満年齢、十干・十二支の並びを身につける1日5問のゲーム。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/wareki-yomi/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・好きなだけ）、解いた種類の「覚えること」と和暦の早見が見られる「和暦帳」があります。
- まちがえても選び直せます。正解すると「なぜ」と出典が出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段です。
- 年や日付は毎回種から作るので、同じ問題がなかなか続きません。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 中身の出どころ

元号の始まり・年齢の数え方・十干十二支は、次の公的な資料で確かめたものだけを使っています。

- [e-Gov 法令検索 元号を改める政令（昭和64年政令第1号）](https://laws.e-gov.go.jp/law/364CO0000000001)：元号を平成に改める。公布の日（昭和64年1月7日）の翌日から施行 → 平成元年＝1989年1月8日から
- [e-Gov 法令検索 元号を改める政令（平成31年政令第143号）](https://laws.e-gov.go.jp/law/431CO0000000143)：元号を令和に改める。平成31年4月30日の翌日から施行 → 令和元年＝2019年5月1日から
- [国立公文書館 日本のあゆみ「大正と改元」](https://www.archives.go.jp/ayumi/kobetsu/m45_1912_01.html)：明治45年7月30日に大正と改元
- [国立公文書館 日本のあゆみ「昭和と改元」](https://www.archives.go.jp/ayumi/kobetsu/t15_1926_01.html)：大正15年12月25日に昭和と改元
- [国立公文書館 日本のあゆみ「鳥羽・伏見の戦い」](https://www.archives.go.jp/ayumi/kobetsu/m01_1868_01.html)：明治元年＝1868年
- [e-Gov 法令検索 年齢計算ニ関スル法律](https://laws.e-gov.go.jp/law/135AC1000000050)：年齢は出生の日から数える
- [国立天文台 暦計算室「六十干支」](https://eco.mtk.nao.ac.jp/koyomi/faq/60kansi.html)：十干・十二支の字と読み、六十干支の並び（甲子から癸亥まで60）

「2026年は何どし？」のような年と干支の組み合わせは、公的な資料で確かめられなかったので出していません。明治5年までの旧暦の日付もあつかいません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を Google から読み込むとき（保存した文字を確かめ直すときも）、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
